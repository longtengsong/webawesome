## 屏幕阅读器支持

我们致力于让我们的网站对所有人都可访问。我们特别测试以下屏幕阅读器和浏览器组合：

- NVDA + Chrome
- NVDA + Firefox
- VoiceOver + Safari

我们努力使所有组件都可访问，但屏幕阅读器和浏览器组合有时会表现不可预测。我们致力于在可访问性问题出现时及时解决，并将尽最大努力为所有用户确保良好的体验。

## 旧版浏览器支持

虽然我们专注于现代浏览器，但我们理解有些用户可能正在使用旧版本。对于关键问题，我们将根据自行决定为旧版浏览器提供修复和/或变通方案。
